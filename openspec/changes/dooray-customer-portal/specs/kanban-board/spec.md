# kanban-board

## ADDED Requirements

### Requirement: 상태 컬럼 보드
보드 화면은 해당 고객사 프로젝트의 Dooray 워크플로우 상태를 컬럼으로 표시해야 한다(SHALL). 컬럼 명과 순서는 Dooray 워크플로우를 그대로 따르며 별도 상태 매핑 테이블을 두지 않는다(MUST NOT).

#### Scenario: 보드 로딩
- **WHEN** 매핑된 사용자가 보드 화면에 진입하면
- **THEN** Dooray 워크플로우 기준 컬럼과 각 컬럼의 업무 카드가 표시된다

#### Scenario: 빈 컬럼
- **WHEN** 특정 상태에 업무가 없으면
- **THEN** 해당 컬럼은 빈 상태로 표시된다

### Requirement: 업무 카드
카드는 제목, 업무 번호, 작성일, 최근 수정일, 중요도(우선순위), 태그를 표시해야 한다(SHALL). 카드 클릭 시 업무 상세로 이동한다.

#### Scenario: 카드 클릭
- **WHEN** 카드를 클릭하면
- **THEN** 해당 업무 상세 화면으로 이동한다

### Requirement: 드래그 앤 드롭 상태 변경
카드를 다른 컬럼으로 드래그하면 해당 상태로 변경하는 API를 호출해야 한다(SHALL).

#### Scenario: 드래그 성공
- **WHEN** 카드를 다른 상태 컬럼에 드롭하면
- **THEN** 상태 변경 API 호출 후 보드를 갱신하고 카드가 새 컬럼에 표시된다

#### Scenario: 드래그 실패
- **WHEN** 상태 변경 API가 실패하면
- **THEN** 카드는 원래 컬럼으로 복귀하고 오류 메시지를 표시한다

### Requirement: 보드 도구
보드는 새 업무 등록 진입점과 수동 새로고침을 제공해야 한다(SHALL).

#### Scenario: 새 업무 진입
- **WHEN** "새 업무" 버튼을 클릭하면
- **THEN** 업무 등록 화면(또는 모달)이 열린다

#### Scenario: 새로고침
- **WHEN** 새로고침을 실행하면
- **THEN** Dooray에서 최신 업무 목록을 다시 조회해 보드를 갱신한다
